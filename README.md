# Life Dashboard Hub

Life Dashboard Hub is a self-hosted server for [Life Dashboard Companion](https://github.com/owen282000/life-dashboard-companion-app).

The project aims to provide a central place to collect and manage Android usage data, making it possible to view screen-time reports across multiple devices and share usage summaries with family members.

## Goals

- **Self-hosted:** Keep your data on infrastructure you control.
- **Privacy-focused:** Your usage data is yours. No advertising or selling personal usage data.
- **Multi-device:** Bring usage data from multiple Android devices into one place.
- **Family-friendly:** Make it possible to share usage reports with family members while respecting individual privacy.

## Status

Life Dashboard Hub is currently in the planning stage. Features and documentation will be added as development progresses.
